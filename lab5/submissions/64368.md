## 1. Initial CI Analysis

The original CI workflow contains separate jobs for restoring, building, testing, and publishing the backend, as well as installing, testing, and building the frontend.

Three examples of repeated work:
1. The backend repeatedly checks out the repository and sets up .NET.
2. The backend restores dependencies in multiple jobs.
3. The frontend repeatedly checks out the repository, sets up Node.js, and installs npm dependencies.

Backend jobs run sequentially because they use `needs`. Frontend jobs also run sequentially. Backend and frontend pipelines can execute in parallel.

Each GitHub Actions job uses a separate runner, so files generated in one job are not automatically available in another job.

## 4. Dependency Caching

NuGet caching was configured with `actions/cache@v6`, using `~/.nuget/packages` and a key based on the operating system and `.csproj` files.

npm caching was configured with `actions/setup-node@v7`, using `cache: npm` and the frontend `package-lock.json`.

In the observed logs:
- The NuGet cache was initially missing (`Cache not found`).
- The npm cache was successfully restored (`Cache hit`).
- Both optimized jobs completed successfully.

A cache speeds up dependency installation across workflow runs. An artifact stores output files produced by a particular workflow run.

Caching npm dependencies does not eliminate the need for `npm ci`.

A subsequent run is needed to verify whether the NuGet cache saved by the first run is restored successfully.

In the observed logs:
- During the first optimized run, the NuGet cache was not found.
- During a subsequent run, the NuGet cache was successfully restored (`Cache hit`).
- The restored NuGet cache was approximately 81 MB.
- The NuGet cache restoration step took 3 seconds.
- The npm cache was also successfully restored (`Cache hit`).

The optimized backend job completed in 27 seconds in the subsequent run. An earlier optimized run completed in 32 seconds. These results show successful cache restoration, although the difference in total duration cannot be attributed to caching alone.
